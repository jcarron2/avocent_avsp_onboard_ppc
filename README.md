# avocent_avsp_onboard_ppc
PPC companion daemon (avsp_client_ppc) replacing Avocent's Java KVM client on the DSR2030 (x030) IP KVM appliance. Stored and runs natively on-device (PowerPC 405EP), streaming DVC15 video and HID input to any modern browser, no Java/Web Start needed. Includes a firmware customizer toolkit and a self-healing on-device watchdog.
